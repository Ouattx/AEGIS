Findings and limits

  • Single-core ingest+validate: 23,367 events per CPU-second at 10,000 lines; feature windows 60,271.
  • Sharded x4 (ingest + windows + SENTINEL, wall clock) vs one core doing ingest + windows (CPU time): 10,000 lines 2.39x, 100,000 lines 2.84x, 1,000,000 lines 2.70x (speed-up is limited by the single coordinator, which reads, identifies and routes every record, and by other processes sharing this host).
  • At 1,000,000 lines the configured traffic needs 50,000 events/s; one coordinator handled 29,495 events/s here, so a deployment at that size runs several coordinators fed by collector-side partitioning (Kafka partitions keyed with aegis.scale.kafka_partition_for_line).
  • Feature-window state is bounded streaming state: 119 KB per line measured with a full 24 h window (119 GB at 1,000,000 lines, split over the line shards), flat once the window is full; whatever the event rate a line holds at most 256 KB of packed records (hops over the caps keep a coordinated sample, see aegis.sentinel.features).
  • RESONANCE at 1,000,000 lines on one population (extrapolated (power law fitted on 4 measured line counts [1000, 2500, 5000, 10000])): 7,592 CPU s and 74 GB per hourly run (detection does not shard by destination: the permutation null needs every destination of each line). Split into independent sub-populations of 10,000 lines (region / BNG; see aegis/scale/INTEGRATION.md), one run needs 1.7 GB and 33 CPU s, so 100 runs take 0.9 cores per hour with RAM bounded by the runs executing concurrently.
  • Sharded RESONANCE preparation (10,000 lines, 4 workers) took 6.3 s vs 4.4 s single-node: at this size shipping the frames to worker processes costs more than the join saves; it pays off only when the line shards already hold their data (Kafka / Kubernetes executors), not with the local executor.
  • 1M-line rows process the same event budget as smaller scales over a shorter simulated window; throughput and per-line state lookups are measured with 1M distinct lines, full-day quantities are extrapolated as stated.
